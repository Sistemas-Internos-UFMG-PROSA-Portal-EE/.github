## Projetos

### PROSA — Sistema de Gestão da Pós-Graduação

Sistema para apoiar e sistematizar os processos administrativos e acadêmicos dos programas de pós-graduação da Escola de Engenharia. Busca centralizar solicitações, organizar fluxos administrativos, melhorar a rastreabilidade das atividades e apoiar a gestão dos programas, respeitando as particularidades de cada um.

### Portal EE — Novo Portal da Escola de Engenharia

Reformulação do portal institucional da Escola de Engenharia. O objetivo é modernizar a navegação, organizar melhor as informações, facilitar o acesso a serviços e conteúdos institucionais e tornar o portal mais acessível e intuitivo.

## Fluxo de desenvolvimento

O planejamento e a gestão das atividades ficam no **OpenProject**. O **GitHub** é utilizado para o trabalho sobre o código:

| Etapa | Uso do GitHub |
| :--- | :--- |
| Versionamento | Armazenamento do código-fonte e controle de versões |
| Desenvolvimento | Trabalho colaborativo por meio de branches |
| Revisão | Revisão de código utilizando Pull Requests |
| Organização | Organização e manutenção dos repositórios |
| Histórico | Registro do histórico de alterações |

O GitHub Project complementa o OpenProject, oferecendo uma visão do andamento técnico das atividades de desenvolvimento, com quadros separados para PROSA e Portal EE.
